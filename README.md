# Rođendanska pozivnica

Mobilno-prva, interaktivna pozivnica izrađena kao statična web-stranica.

## Prilagodba pozivnice

U datoteci `index.html` upiši svoje podatke:

- `[vrijeme]` — vrijeme početka proslave
- `[mjesto proslave]` — naziv lokacije
- `[adresa ili kratke upute]` — adresa ili upute za dolazak

Pozivnica je unaprijed postavljena za 1. siječnja i slavi 50. rođendan uz doček Nove godine. Po želji izmijeni datum, tekst pozivnice i naslov stranice.

## Objavljivanje na GitHub Pages

1. Na GitHubu otvori **Settings → Pages**.
2. Pod **Build and deployment** odaberi **Deploy from a branch**.
3. Odaberi granu `main` i mapu `/ (root)`, zatim klikni **Save**.

Stranica će biti objavljena na adresi GitHub Pages prikazanoj u postavkama repozitorija.
